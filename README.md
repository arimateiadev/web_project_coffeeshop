# Web Project Coffee Shop

## Descrição

Projeto da Sprint 4 do bootcamp de Desenvolvimento Web da Tripleten.
Landing page responsiva para uma cafeteria fictícia, com seções de receitas,
reserva de mesa e menu. Desenvolvido seguindo a metodologia BEM.

## Funcionalidades

- Layout 100% responsivo para desktop, tablet e mobile
- Formulário de reserva de mesa funcional
- Seção de vídeos de receitas incorporados
- Animações e transições em CSS

## Tecnologias utilizadas

- HTML5
- CSS3
- Metodologia BEM
- Flexbox
